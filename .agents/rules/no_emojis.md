# Rule: No Emojis in Pluto

Under no circumstances should emojis (such as 🔍, 🎮, 📦, ⚡, ▶, 🔄, ←, etc.) be used in the Pluto UI, code, console logs, or documentation.
All buttons, indicators, and text must be rendered in clean, minimalist plain text only.
- Use "back" instead of "← back"
- Use "launch" instead of "▶ launch"
- Use "sync to sls" instead of "⚡ sync to sls"
- Use "switch mode" instead of "🔄 switch mode"
- Use "search games..." instead of "🔍 search games..."
